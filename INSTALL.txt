Burst Clicker — install, update, use
====================================

Clicks the "Yes" button on a page automatically: 1:00 pm Monday-Friday and
10:00 am Saturday-Sunday, every day, timed to the website's own clock.
No markers to place, nothing to re-arm.

INSTALL (about a minute)
------------------------
1. UNZIP THIS FILE. Chrome needs a folder, not a zip. You get a folder called
   "burst-clicker" that contains manifest.json.

2. MOVE THAT FOLDER SOMEWHERE PERMANENT (e.g. Documents). Chrome loads it from
   that exact place every time it starts — don't delete it afterwards.

3. Open Chrome and go to:  chrome://extensions

4. Turn ON "Developer mode" (toggle, top right).

5. Click "Load unpacked" and select the "burst-clicker" folder — the one that
   directly contains manifest.json, not a folder above it.

6. Click the puzzle-piece icon in the Chrome toolbar and pin "Burst Clicker".

USE
---
1. Open the page that shows the "Yes" button. Leave it open — it can be in the
   background or in another window.
2. Click the Burst Clicker icon -> "Turn on for this tab".

Done. A green ring appears around the Yes button it will click, labelled
"Burst Clicker will click this" with the time. No Yes on screen? An amber notice
in the top-right corner says so (at click time it keeps looking for one).

SEVERAL LEAD PAGES? Open all of them first, then click the icon once ->
"Turn on for every tab with a Yes". Every tab showing a Yes is turned on at once.
A Yes that is disabled until 1 pm is fine: it shows an amber ring and gets
clicked the moment it enables.

It clicks Yes once at 1 pm on weekdays and 10 am on weekends, every day,
until you click "Turn off for this tab" or close the tab. It stays on through
page reloads and Chrome restarts.

- "Test now" (with a Yes on screen) clicks it in about a second, once — a quick
  check that it finds the button. It does not change the daily schedule.
- "Reset to schedule" puts the times back to 1 pm / 10 am.
- KEEP THE COMPUTER AWAKE at those times. A sleeping computer cannot click; it
  would click late, when it wakes.

UPDATE
------
1. Download the new zip and unzip it.
2. Replace the CONTENTS of your existing burst-clicker folder with the new files
   (same folder, same place — this keeps your settings).
3. chrome://extensions -> click the reload arrow on the Burst Clicker card.
Do not "Remove" and re-load from a different folder: Chrome treats that as a new
extension and your settings start over.

THINGS WORTH KNOWING
--------------------
- Chrome will warn "Disable developer mode extensions" now and then. That's
  normal for any extension not installed from the Chrome Web Store. Keep it.
- It looks for a visible, enabled button labelled exactly "Yes". If there are
  several, the top-most one is clicked. A Yes inside an embedded frame is not found.
- chrome:// pages, the Chrome Web Store and PDFs can't be clicked by any
  extension. That's a Chrome rule, not a bug.
- "Trusted clicks" is optional, for sites that ignore normal clicks. Chrome
  shows a "being debugged" banner while it is on.
- The older marker mode is still there: turn off "Auto-click Yes" in the popup.

Full guide: open GUIDE.html (in this folder) in any browser.

Automating clicks may be against some sites' terms of service. Your call.
